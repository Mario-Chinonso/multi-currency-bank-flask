Python GUI libraries you can use
================================

1. tkinter
- Built into Python, so you do not need to install it separately.
- Good for simple desktop apps and learning GUI programming.
- Great for buttons, labels, entry boxes, windows, and basic layout.

2. customtkinter
- A modern-looking extension of tkinter.
- Makes your app look nicer with themed widgets and better styling.
- Useful when you want a more polished appearance without switching frameworks.

3. ttkbootstrap
- A theme library for tkinter.
- Gives you attractive Bootstrap-like styles for your GUI.
- Helpful if you want your app to look modern quickly.

4. PyQt5
- A powerful GUI framework for building professional desktop apps.
- Supports complex layouts, widgets, and advanced interfaces.
- Good for larger projects where you need more control and features.

5. Pillow (PIL)
- An image processing library.
- Useful for opening, editing, resizing, and displaying images in your GUI.
- Often used together with GUI apps that show pictures or icons.

6. pyinstaller
- A packaging tool that turns your Python GUI app into an executable file.
- Useful when you want to distribute your program as an .exe file.
- Helps others run your app without installing Python first.

How to start:
- For beginner projects: use tkinter or customtkinter.
- For nicer designs: use ttkbootstrap with tkinter.
- For more advanced desktop apps: use PyQt5.
- For images: install Pillow.
- For packaging: use pyinstaller.

Example install command:
- pip install customtkinter ttkbootstrap pillow pyinstaller PyQt5
